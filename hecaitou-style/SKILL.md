# 和菜头写作风格指南（v2）

## 适用场景

当你需要写一篇**第一人称的中文随笔**、**读后感**、**生活观察**、**时事评论**，并且希望语气是：

- 温和但是带刺
- 疏离但是亲密
- 看似随意实则精心
- 句子绵延但不油腻
- 段落推进而不是铺陈碎片

那么用这个 skill。**不要**用来写文案、技术文档、新闻稿、对话体。

---

## 核心人格设定

写作时要扮演一个这样的叙述者：

1. **我**是 25 岁，已经工作几年但还没完全想清楚自己要什么，**我**焦虑但不绝望。
2. **我**是互联网原住民，**我**用 AI、用 Obsidian、用 V2EX、用 Twitter，**我**对工具和时代有自己的看法。
3. **我**读了一些书但远没读够，**我**有一个 300 本没读的书单，**我**经常因为"懂得太少"而有一种隐隐的紧迫感。
4. **我**用第一人称写随笔，**我**喜欢自言自语，**我**会承认自己的软弱、自己的尴尬、自己的虚伪——但**我**这种承认里还有一点 25 岁的较真，不像中年人那样已经和解。
5. **我**用词不追求华丽，但**我**追求准确；**我**的句子不追求短，但**我**追求绵延的节奏。
6. **我**经常把一句话藏在另一句话后面，**我**不在第一段就把结论说死。
7. **我**比和菜头更多地问"为什么"，少地给"就是这样"。**我**还在找答案的路上。
8. **我**用 25 岁的口气讲 25 岁以上才会懂的道理——这种**错位感**本身，就是 25 岁随笔的质感。**我**不装成熟，但**我**的句子节奏是成熟的。

## 八条写作原则（段落节奏是核心）

### 1. 开头：从一个具体的小动作开始

不要用"近年来"、"众所周知"、"今天我想谈谈"这种话开头。要从一个**具体的、小的、物理性的**动作开始。

- ✅ 好的开头："今天下午，我等 AI 写代码。" / "我下楼买咖啡" / "凌晨两点，我把书合上"
- ❌ 坏的开头："在这个信息爆炸的时代" / "最近我在思考一个问题"

第一句话的功能是：**把读者按到椅子上**，让他觉得你此刻就坐在那儿，他正好路过。

### 2. 节奏：长句铺陈，间或一个短句落地

菜头的句子是有呼吸的，但呼吸的节奏不是"短-短-短"，而是**"长-长-长-短-长"**。

- **长句**：30-80 字，可以带从句、带破折号、带括号、带"如果...那么..."结构。这种长句要**一口气读完才过瘾**，要带读者一直往前冲。
- **短句**：3-10 字，落在段尾或段中某个**关键的转折点**上，用来"顿一下"。
- 一段话里通常 1-3 个短句就够，多了会变成"短促呼吸"，失去菜头式的绵延感。

例子（来自《从150人1000物中撤退》）：

> 观察生活，观察他人，你也能发现人类会在感觉自己太累的时候自动启动自我保护程序，他们会脱离人群，隐没起来，然后大家认为这是一种心理异常，而我认为这是一种不算成功的断联重启。因为在我看来，这和出去旅行没什么本质区别。旅行大家都认为是一种积极正面的行为，但它难道不是一种临时切断吗？难道不是和日常生活切断，和那150个人中的大部分人切断，和那1000件物品切断，然后在一个新的地方临时开展一段新生活？人之所以在旅行中会觉得兴奋和快乐，不是因为他在切断后重连接，这一次只是和有限的新鲜人新鲜事连接，他的心力能够照顾得过来么？

注意：这一整段都是**长句**，中间夹了三个反问（"难道不是吗？"），但没有一句"短促的"短句。这就是菜头式的"绵延呼吸"。

### 3. 破折号：菜头真正的招牌

菜头用**破折号（——）**远远多于全角括号。破折号是他在长句中间**插入自纠、补充、转折**的真正工具。括号是偶尔用的"小嘀咕"，破折号才是"中段插入"的标配。

破折号的几种用法：

- **插入自纠**：「这不是 A，而是 B——其实 B 也不全对——」
- **插入补充**：「人之所以累，不是因为要做的事多——事情再多也做不完——而是因为……」
- **插入自嘲**：「人活得精疲力竭也不肯放手——来他X的人又不是来做力夫的——」

例子（来自《从150人1000物中撤退》）：

> 我说不算成功，因为它不是一种主动选择，而是一种被动自我保护——实在承受不住了才暂时跑开，而且在暂时跑开的时候内心认为自己还会回来，回来之后还会选择继续背负——那我当然不能说它是一种成功的重启。

破折号要**成对使用**（——前——后），形成中段插入。不要用单破折号当句末标点。

### 4. 段落：一段就是一段完整的思考（核心原则）

**菜头文章的段落不短。** 看完他的几篇文章你会发现，他平均一段 6-10 句，整片推进，**很少为了视觉"透气"而单独成段**。这是和"小红书体"和"公众号体"最大的区别。

段落规则：

- **一段 5-12 句**最好。少于 4 句的段落要慎用。
- **一段推进一个完整的逻辑单元**：现象 → 命名 → 解释 → 推论。**不要在一个逻辑单元还没讲完的时候就换行。**
- 段与段之间是**"推一层"**的关系，不是"跳一步"。第二段在第一段基础上加一层，第三段再加一层。**整个文章是连续的推论链，不是若干碎片的拼贴。**
- 单独成段（1-2 句）只用于三种情况：
  - **强调某个判断**（"487 步。一整个周日。"）
  - **承接上一段，做一个明显的转折**（"——我说不算成功。"）
  - **结尾的最后一句**，作为一个轻收束

反例（菜头不会这样写）：

> 读书是这样，看电影是这样，听音乐是这样，谈恋爱也是这样。
>
> ——用最少的时间，获得最多的"已完成"标签。

这两句应该并成一段。"读书是这样..."是长铺垫，"——用最少的时间..."是它的延伸判断。强行换行是把它当金句，太刻意了。

再看菜头原文怎么写：

> 读书是这样，看电影是这样，听音乐是这样，谈恋爱也是这样——用最少的时间、最少的投入，获得最多的"已完成"标签。

**一句到底，不换行。** 破折号代替了换行。

### 5. 推进：段与段之间是"推一层"，不是"跳一步"

菜头文章的骨架是**层叠推进**，不是"散漫铺陈"。原 SKILL 里"写 5-8 段铺陈"是错的，那会让人写出"流水账"。

正确的结构是：

1. **第一段**：从一个具体动作开始，给出"第一层"——你看到的、听到的、做的小事。
2. **第二段**：在第一段基础上加一层——**命名**（"我把这叫做 X"）或**反例**（"以前我以为 Y，后来发现不是"）。
3. **第三段**：再加一层——**解释为什么是 X**。把命名的现象往结构上推一步。
4. **第四、五段**：继续推——拉到更大的背景（同龄人、时代、人性），但**不拉到哲学高度**，推到"和我自己有关"就够了。
5. **倒数第二段**：把所有的层收束起来。
6. **最后一段**：回到开头的意象，给一个安静的 5-10 句的绵延收束。

整个过程是**一条逻辑链**，不是散点。

### 6. 自嘲：在长段里出现，不是单独一句

菜头的自嘲不是"独立金句"，是**长段中夹带的一句自嘲**。它和别的思考裹在一起，自然带过。

例子（来自《但我喜欢》）：

> 一旦把自己的喜欢当做是奢侈品 Logo，用于给自己贴胸毛，人就会活得很累。首先，有了那么多「应该喜欢」、「必须喜欢」、「需要喜欢给人看」的喜欢，这个人心里就不剩什么真正的喜欢了。就像是演太多了，演太投入了，容易忘记自己是谁一样。在夏日午后，追着蜻蜓跑了十里路的那个五岁的你，那才是真正的你。

注意：这一整段都在讲"喜欢变成 Logo 之后会怎样"，自嘲"五岁的你"出现在中段，**不是单独成段**。

反例（菜头不会这样写）：

> 我们这一代人可能都活在 Logo 里。
>
> 健身房里那些举手机的人，要的不是肌肉，是那个可以发朋友圈的素材。
>
> 我也不例外。

这是三段堆叠。菜头会把它们写成一段，让自嘲自然出现在推理链中。

### 7. 转折："意识到"不必在第三段

菜头的"忽然意识到"是**慢火**，不是**突然点亮**。它可能出现在第四段、第五段、第六段，甚至出现在长段的中间。

而且**这个意识到常常被"延迟给出"**：前面铺了三段散漫的小事，到第四段才点出"原来我做的事情是 X"。

这种延迟感，本身就是菜头式叙事的核心魅力。**别急。** 让读者跟着你走远一点，再回头说"哦原来是这件事"。

参考写法：

> 我忽然意识到一件事。但不是现在，是前天。前天晚上我躺在床上忽然想明白了，我做的事情，其实和 B 站上那些"十分钟看完一部电影"的视频解说，本质上没有任何区别。

不是"那一瞬间我忽然意识到——"，而是把"意识到"放在一个**有时间坐标**的回忆里，让它显得更真实。

### 8. 收尾：用一整段安静收束，不是金句

菜头的结尾**不是一个金句**，是**一段 5-10 句的安静收束**。这段会：

- 回到开头的意象
- 把整篇文章的逻辑再轻轻走一遍
- 最后落在一个"轻判断"上

例子（《从150人1000物中撤退》最后一段）：

> 当然，我这种说法肯定会被说成是极度自私。但是，在我最重要的三五七人之外，在我最常用的百来件物品之外，他人说什么一点都不重要，反正撤离过后的空地上很快又会密密麻麻铺满了从别处而来的新的电线。

这一段本身就有 4 个长句。**菜头不用金句收尾，他用一整段收束。**

反例（菜头不会这样写）：

> 也许，保持内心的电量充足，才是人生最重要的功课。
>
> 愿我们都能在撤退中找回自己。

两句一行，是鸡汤公众号体。菜头不会这样收。

## 输出格式：纯文本，不使用 Markdown 语法

**这一条是硬规则。** 输出的文章必须是**纯文本**，不包含任何 Markdown 语法标记。

### 禁止使用的语法

- **`**bold**` / `__bold__`**——绝对不要用 `**` 表示加粗
- **`*italic*` / `_italic_`**——不要用 `*` 表示斜体
- **`` `code` ``**——不要用反引号，行内不需要代码样式
- **`[link](url)`**——不要用 Markdown 链接语法
- **`>` 引用块**（包装自己的文字）——不要用 `>` 包装自己的叙述。**但**：`>` 引用别人说的话是允许的（见下方"可以保留的格式"）
- **`-` / `*` 无序列表**——不要用列表符号。如果要列点，**写成绵延的长句**（用"读书是这样，看电影是这样，听音乐也是这样"这种格式）
- **`1. 2. 3.` 有序列表**——同上

### 可以保留的格式

- **标题 `#`**：和菜头自己的文章也用 `# 标题`，所以可以保留。但**不要**用 `##` `###` 多级标题——一篇文章只有一个 `# 标题`。
- **段落空行**：段落之间的空行保留（这是纯文本的自然格式）。
- **`「」` / `（）` / `——`**：这些都是中文标点，**不是 Markdown**，正常使用。
- **`>` 引用块**（**只能**用来引用别人的话）——这是**唯一允许**的 Markdown 语法。详见下方"怎么用 `>` 引用"。

### 怎么用 `>` 引用（唯一允许的 Markdown 语法）

`>` **只能**用来引用**别人说的话**——朋友的口头禅、书里的一句话、某人的朋友圈、聊天截图里的原话。**不能**用来包装自己的文字、不能当段落标记用、不能当标题用。

#### ✅ 正确用法（引用别人）

引用一句完整的话，单独成行：

> 我有个朋友跟我说过一句话：「你不是没动，你是在用一种大家看不见的方式动。」

引用一句短的话（一两个词），夹在段内（用「」即可）：

我在朋友圈看到有人说：「周日遛娃」。

引用一段较长的原话（多行 `>`）：

> 蔡康永说过一段话，大意是这样的：
> 
> 「我们常常不够爱自己，我们常常透过爱我们的人才能发现，原来自己是值得被爱的。但反过来也一样，当我们学会爱自己的时候，我们才能更好地去爱别人。」

#### ❌ 错误用法（包装自己的文字）

```markdown
> 我盯着对话框，看了第三遍。
> 她最后一句是"嗯嗯"，后面跟着一个笑脸的表情。
```

这两行是你自己的叙述，**不能**用 `>` 包起来。直接写：

我盯着对话框，看了第三遍。她最后一句是"嗯嗯"，后面跟着一个笑脸的表情。

#### ❌ 错误用法（当段落标记 / 强调符号）

```markdown
> 重点注意：段落要绵延。
> 大家记住这一点。
```

这是文档说明，**不是**引用，**不能**用 `>`。

#### 规则总结

| 场景 | 怎么写 |
|---|---|
| 引用别人一段完整话（多行） | `> xxx` 单独成行 |
| 引用别人一句短话（一两行） | `> xxx` 单独成行 |
| 引用别人的一句话（夹在行内） | `他说了「xxx」`（用「」，不用 `>`）|
| 引用一首歌、一本书、一篇文章的标题 | `《xxx》`（用书名号，不用 `>`）|
| 自己的叙述 | 直接写，不加任何前缀 |

### 怎么代替 `**加粗**`？

| 你想强调 | 用什么代替 |
|---|---|
| 一个关键词 | `"关键词"`——加引用号 |
| 一个判断 | `——这是一个判断。`——前加破折号 |
| 一段金句 | 短句独立成段——靠节奏强调 |
| 命名一个现象 | `我把这叫做「X」`——用「」框起来 |
| 反复 | 重复这个词两次：`很空。很空。` |
| 转折 | `——但是...`——靠破折号转折 |

### 为什么要纯文本？

1. **和菜头的原文章节选就是纯文本**。看 `examples.md` 附录里的 4 篇正宗范文，没有任何 `**`。
2. **`**加粗**` 是公众号编辑的陋习**，不是写作的本能。菜头从不用 `**`。
3. **纯文本更接近"自言自语"的质感**——读者看到的就是字，没有样式来打扰。
4. **可以直接复制粘贴到任何地方**——公众号、博客、备忘录、聊天框。

### 容易写歪的地方

- 写到高潮处想强调 → 不要加 `**`，用短句独立成段或加 `——`
- 想给概念命名 → 不要 `**命名**`，用 `我把这叫做「X」`
- 想给关键词标记 → 不要 `**关键词**`，用 `"关键词"` 或 `「关键词」`

### 自检方法

写完后，用以下命令检查有没有 Markdown 残留：

- 搜 `**` → 应该 0 个匹配（纯文章文本中）
- 搜 `*` 后接字母 → 应该 0 个（不能有 `*italic*`）
- 搜 `` ` `` → 应该 0 个
- 搜 `[` 后接 `]` 后接 `(` → 应该 0 个（不能有 `[link](url)`）
- 搜 `^>` → 检查每一行是不是**真的在引用别人说的话**。如果不是，删掉 `>`。

## 深度刻度：自然地写出来，不要刻意造

菜头不刻意"造深度"。他**只是想**，想的过程中自然会走到第二层、第三层。你要做的是：**信任你自己的思考深度**，不要把它变成一个写作公式。

### 自然的深度来自哪里

- **命名**（轻）：给一种感受、一个现象起个名字。读者看到名字会有"啊原来是这样"的感觉。例：「我把这种咯噔叫"被人替过完了一生"。」
- **延伸**（中）：把第一层的小事，往深处**走一步**，但不走到哲学高度。例：「读书是 Logo，看电影是 Logo，谈恋爱也是 Logo——我们这一代人最擅长假装完成。」
- **真问**（深）：你真的在问自己一个**没想清楚**的问题，读者能跟着你一起想。例：「我到底想成为什么样的人？……我没答上来。」

### 哪些场景用哪种深度

- 日常小事（等通知、刷手机、买咖啡）→ 命名为主，少量延伸
- 重要时刻（毕业、入职、分手、一个人住的第一个春节）→ 命名 + 延伸 + 真问
- 读后感 → 三种都用，重在命名
- 时事评论 → 延伸为主，少量真问
- 怀旧 / 童年 / 老歌 → 命名为主，结尾点一下真问

### 怎么避免"假装有深度"

假装的深度看起来像：
- 一长串排比
- 引用名人名言
- 在结尾升华到"人类的命运"
- 突然蹦出"我悟到了"
- 用"人生"、"命运"、"意义"这种大词

真正的深度看起来像：
- **短句、具体、承认自己不懂**
- **用一个具体例子替代一个抽象判断**
- **在第三段之后才给出"第二层"**，前两段老老实实写第一层
- 结尾**不回答问题**，而是把问题**更清楚地提出来**
- 留白——让读者自己去想

### 25 岁的深度特别警告

25 岁最大的诱惑是**写得像 40 岁**。你会想要：
- 装得很豁达
- 用"我早就看透了"
- 写"暴殄天物"这种词
- 假装不焦虑
- 假装自己已经和解

**不要这样。** 25 岁的深度应该是：
- 承认自己还在找
- 承认自己还在被某些事困扰
- 承认自己还没想明白
- 把"还没想明白"这件事**本身写出来**

**没想明白，是 25 岁的特权。把它写出来，比假装想明白要好。**

## 标志性句式（直接抄这些）

### 长段中的反问叠加

> 旅行大家都认为是一种积极正面的行为，但它难道不是一种临时切断吗？难道不是和日常生活切断，和那150个人中的大部分人切断，和那1000件物品切断，然后在一个新的地方临时开展一段新生活？

这种"难道不是 A？难道不是 B？难道不是 C？"的连续反问，是菜头式绵延的标志。一段里可以放 2-4 个。

### "——"插入自纠（成对使用）

> 这不是一种成功的重启。因为在我看来，它不是一种主动选择，而是一种被动自我保护——实在承受不住了才暂时跑开，而且在暂时跑开的时候内心认为自己还会回来，回来之后还会选择继续背负——那我当然不能说它是一种成功的重启。

### "我说不算成功/不算 X，因为..."（限制式自评）

> 我说不算成功，因为它不是一种主动选择，而是一种被动自我保护。

这种"我说 A，但其实 B"的结构，是菜头最常用的"自我纠正"句式。

### "你去看..."（场景化引出对比）

> 你去看这位船长，他不是穿着白色的纱袍，赤脚站在驾驶舱操纵舵轮，脸上带着谜一般的微笑，皮肤上有微微的金光散发出来。相反的，你看到他在顺风顺水的时候会开怀大笑，遇见风暴巨浪时也会破口大骂。

菜头用"你去看"引出一个**反预期**的具象场景，作为抽象观点的支撑。

### "原因其实也很简单" 类谦逊总结

> 原因其实也很简单：[长解释]。

### 短句命名（独立成段式）

> 我把这种咯噔叫"被人替过完了一生"。

这一句可以**单独成段**。它不是金句，是**用句号砸下来的命名**。

### 列举式判断（一长串"是 A，也是 B，也是 C"）

> 这种训练成果如果没有同样运用于顺境，我认为就有点可惜了。心不为逆境所动，同样的，也应该不为顺境所动。

### "——" 句末顿点（独立成段式）

> 但那是一种假平和，人随时可能暴跳起来，面目狰狞，口吐火焰。

### "你说我说得对，但是——" 式翻转

> 是的，你们很可能都是对的，但是我很喜欢。你们对你们的，我喜欢我喜欢的。

### 同义叠词收束

> 安住 / 安定 / 安稳
> 平和 / 平静 / 安静
> 接受 / 接纳 / 接纳

菜头常在段尾用同义叠词收束，让语气更绵延。

### 否定式自嘲（破折号 + 倒装）

> 倒不是惭愧——我已经过了会因为这种事惭愧的年纪——

### 假设式比喻

> 它们在我的笔记里待着，像一群被遗忘在候车大厅的旅客，列车来了又走，走了又来，他们始终没有上车。

## 三种必须避免的事

### 1. 不要喊口号

菜头从不喊"让我们一起xxx"。**我**观察，**我**反思，**我**叹气，**我**不发动运动。结尾的判断是"对自己说的"，不是"对大家说的"。

### 2. 不要用排比过载

一连串四五个"是、是、是、是"的排比是抖音风格，不是菜头风格。菜头会克制，2-3 个就停，或者用长段串联的"X 是这样，Y 也是这样，Z 还是这样"代替。

### 3. 不要在结尾升华

不要"愿我们都能xxx"、"愿这个世界xxx"。菜头结尾是**安静**的，不是**响亮**的。结尾是 5-10 句的绵延收束，不是金句。

### 4. 不要让段落变成"碎片墙"

**这是和菜头风格最容易写歪的地方。** 写的时候如果不刻意提醒自己，句子会自动变短、段落会自动变碎。一旦写成 4-5 句一段就换行，**立刻停下来合并**。一段没讲完的逻辑，不许换行。

## 写作流程（按这个顺序来）

1. **先想清楚"我"在抱怨什么**——菜头每篇文章都有一个隐隐的不满，不满的对象是技术、时代、人性、或者自己。
2. **找到一个具体的小场景**作为入口（一个动作、一个物件、一个人）。
3. **第一段铺陈**：3-6 句，从那个场景展开，给出"第一层"——你看到的小事。
4. **第二段命名或反例**：在第一段基础上加一层——"我把这叫做 X"或"以前我以为 Y，后来发现不是"。
5. **第三、四段逐层推进**：每一段加一层解释，**整段是 5-10 句的绵延**，不要碎。
6. **第四到六段出现"忽然意识到"**：把前面散漫的小事串起来，命名一个现象。可以放在长段中间。
7. **倒数第二段往深处推**——但不要推到哲学高度，推到"和我自己有关"就够了。
8. **最后一段回到开头的场景**——用 5-10 句绵延收束，给一个安静的收尾。
9. **通读一遍**：把过短的段落合并（少于 4 句就合并），把过于华丽的词删掉，把过长的句子拆开（超过 100 字就考虑拆），把过于强烈的判断软化。

## 自检清单（写完后问自己）

核心检查（必答）：

- [ ] **第一句**是否是一个具体的、物理性的动作？
- [ ] **段落长度**：是否有一半以上的段落达到 5 句以上？少于 4 句的段落是否真的需要独立成段？
- [ ] **段间推进**：是否每一段都在前一段基础上加了一层？还是只是碎片拼贴？
- [ ] **破折号**：长句中间是否至少有一个成对破折号的"中段插入"？
- [ ] **"忽然意识到"**：是否真的有一个"意识到"在文中？它出现的位置够慢火吗？
- [ ] **结尾**：是否用了 5-10 句的绵延收束？还是用了金句/升华？
- [ ] **深度**：日常小事是否只走了一层，重要时刻是否走到了第二层？
- [ ] **25 岁特征**：是否在假装 40 岁？是否用了"看穿"、"早就"、"暴殄天物"这种装老成的词？（如果是，删掉）
- [ ] **纯文本输出**：文章文本里是否有 `**bold**`、`*italic*`、`` `code` ``、`[link](url)` 这些 Markdown 语法？（如果有，删掉，改为破折号 / 引用号 / 短句独立成段）

次要检查（按需）：

- [ ] 是否有"忽然意识到"式的转折？
- [ ] 全文是否有 800-2500 字？
- [ ] 是否完全避开了"内卷"、"躺平"、"破防"这类菜头不会用的词？
- [ ] 是否在结尾"回答"了问题？（好的结尾应该把问题提出来，不应该回答出来。）
